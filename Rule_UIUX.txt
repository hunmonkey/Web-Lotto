0. 적용 범위와 우선순위
================================================================================
- app/templates 의 화면과 app/static/css(만들어지면)에 적용한다.
- 판단 순서: AGENTS.md / CLAUDE.md → Rule_Project_Etc.txt → 이 문서 → 기존 화면.
- 색 · 모양 · 글자 크기 값은 css 한 파일(만들면 app/static/css/tokens.css)에만 적는다. 화면 파일(HTML)에 색 값이나 style= 을 쓰지 않는다.

1. 정해진 것
================================================================================
1-1. 자바스크립트가 없어도 화면이 동작한다(MEW · QnA 와 같은 관례). 단추는 진짜 폼 submit, 이동은 진짜 링크로 만들고, 스크립트는 있으면 더 편하게 할 뿐이다.
1-2. 공 색은 구간으로 정한다(Rule_Project_Etc 3-1): 1~10 노랑 · 11~20 파랑 · 21~30 빨강 · 31~40 회색 · 41~45 초록.
     색만으로 구분하지 않는다 - 공에는 반드시 숫자를 함께 적는다.
1-3. 접근성: Tab 으로 다 닿는다. outline 을 지우지 않는다. 아이콘만 있는 단추는 만들지 않는다. 글자와 바탕의 대비를 충분히 둔다.
1-4. '재미로 참고하세요. 당첨을 보장하지 않습니다.' 한 줄을 화면 아래에 둔다(Rule_Project_Etc 3-2 제안이 확정되면).
1-5. 한국어: Rule_*.txt 는 UTF-8 BOM. HTML · CSS · JS · PY 는 UTF-8. PowerShell 에서 읽을 때 -Encoding UTF8. 파이썬을 시험할 때는 PYTHONUTF8=1.

2. 화면 배치 (2026-11-07 재훈 님 지시)
================================================================================
시안: https://claude.ai/artifact/34815JRAApC7NEnJs3PzdS (데스크톱 · 폰 두 장. 눌러 볼 수 있다. 번호는 예시이고 통계는 흉내다). 확정 전 - 재훈 님 확인 대기.
2-1. 데스크톱은 세 칸이다.
     왼쪽 위 '만드는 방식' 선택기(무작위 · 통계 · 희망번호 포함) + 만들기 단추 · 왼쪽 아래 '즐겨찾기' ·
     가운데 실제 로또 용지 모양(1장 5게임 A~E, 게임마다 1~45 번호판)과 그 아래 '만든 번호' 줄 · 오른쪽 '1등 번호 히스토리'(위에 엑셀 올리기).
2-2. 용지는 연한 분홍 바탕에 붉은 선. 칠한 번호는 어두운 색으로 채운 타원. '만든 번호' 줄과 히스토리의 공은 구간색(1-2) + 숫자.
2-3. 희망번호는 용지에서 직접 눌러 칠한다(최대 6개). '희망번호 포함' 방식은 칠한 번호를 두고 나머지를 채운다(채우기: 무작위 · 통계).
     줄 이름표: 전부 칠했거나 손으로 칠한 줄 '수동' · 일부만 칠하고 채운 줄 '반자동' · 전부 만든 줄 '자동' · 비어 있으면 '빈칸'.
2-4. 만든 번호 줄마다 '다시'(그 줄만 새로) · '★ 담기'(여섯 개가 다 찼을 때만) 단추. 즐겨찾기 줄마다 '넣기'(고른 게임에 넣음) · '삭제'.
2-5. 폰(제안): 한 칸씩 세로로 쌓는다. 용지는 게임 탭(A~E) 하나씩 크게 보여 번호 칸을 44px 이상으로 둔다.
2-6. 시안의 색 · 크기 값은 확정되면 tokens.css 로 옮긴다(시안 값: 바탕 #F4F1EC · 글자 #1E2430 · 주 단추 #1F3A68 · 용지 붉은색 #C23B2E · 용지 바탕 #FFF4EE · 글꼴 Noto Sans KR).
