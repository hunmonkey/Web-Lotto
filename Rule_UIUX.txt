0. 적용 범위와 우선순위
================================================================================
- app/templates 의 화면과 app/static/css(만들어지면)에 적용한다.
- 판단 순서: AGENTS.md / CLAUDE.md → Rule_Project_Etc.txt → 이 문서 → 기존 화면.
- 색 · 모양 · 글자 크기 값은 css 한 파일(만들면 app/static/css/tokens.css)에만 적는다. 화면 파일(HTML)에 색 값이나 style= 을 쓰지 않는다.

1. 정해진 것
================================================================================
1-1. 자바스크립트: 로그인 · 로그아웃은 스크립트 없이도 된다(진짜 폼 submit, MEW · QnA 와 같은 관례).
     단 메인 화면의 번호판 칠하기 · 선 그리기 · 만들기 · 즐겨찾기 · 히스토리는 스크립트가 그린다(2026-11-07 - 칠하고 잇는 용지는 폼으로 만들 수 없다). 스크립트가 없으면 메인은 비어 보인다.
1-2. 공 색은 구간으로 정한다(Rule_Project_Etc 3-1): 1~10 노랑 · 11~20 파랑 · 21~30 빨강 · 31~40 회색 · 41~45 초록.
     색만으로 구분하지 않는다 - 공에는 반드시 숫자를 함께 적는다.
1-3. 접근성: Tab 으로 다 닿는다. outline 을 지우지 않는다. 아이콘만 있는 단추는 만들지 않는다. 글자와 바탕의 대비를 충분히 둔다.
1-4. '재미로 참고하세요. 당첨을 보장하지 않습니다.' 한 줄을 화면 아래에 둔다(Rule_Project_Etc 3-2 제안이 확정되면).
1-5. 한국어: Rule_*.txt 는 UTF-8 BOM. HTML · CSS · JS · PY 는 UTF-8. PowerShell 에서 읽을 때 -Encoding UTF8. 파이썬을 시험할 때는 PYTHONUTF8=1.

2. 화면 배치 (2026-11-07 재훈 님 지시)
================================================================================
시안: https://claude.ai/artifact/34815JRAApC7NEnJs3PzdS (데스크톱 · 폰 두 장. 눌러 볼 수 있다. 번호는 예시이고 통계는 흉내다). 확정 전 - 재훈 님 확인 대기.
2-1. 데스크톱은 두 칸이다(2026-11-07 재훈 님: 오른쪽 '1등 번호 히스토리' 칸은 없앤다).
     왼쪽 위 '만드는 방식' 선택기(무작위 · 통계 · 희망번호 포함) + '1등 번호 히스토리' 단추 + 만들기 단추 · 왼쪽 아래 '즐겨찾기' ·
     가운데 실제 로또 용지 모양(1장 5게임 A~E, 게임마다 1~45 번호판)과 그 아래 '번호 이은 선 용지'.
     '1등 번호 히스토리' 단추는 '5게임 만들기' 바로 위에 둔다. 누르면 그 자리에서 목록이 펼쳐지고(다시 누르면 접힘, 단추 글자는 '보기' ↔ '닫기'),
     목록 맨 위에 '엑셀 파일 올리기' 단추가 있다(히스토리 칸이 없어져 올리기 단추를 여기로 옮김 - AI 판단, 확인 대기).
2-2. 용지는 연한 분홍 바탕에 붉은 선. 칠한 번호는 어두운 색으로 채운 타원. 히스토리의 공은 구간색(1-2) + 숫자. 단 '번호 이은 선' 칸만 흑백(검정 · 흰색 · 회색)이다(2026-11-07 재훈 님).
2-3. 희망번호는 용지에서 직접 눌러 칠한다(최대 6개). '희망번호 포함' 방식은 사용자가 칠한 번호만 두고 나머지를 채운다(채우기: 무작위 · 통계).
     채워진 번호는 칠한 번호가 아니다 - '5게임 만들기' · '다시' 를 다시 누르면 채운 번호만 새로 뽑힌다(구현 때 시안의 논리 결함을 고침). 다른 방식은 게임을 통째로 새로 만든다.
     줄 이름표: 전부 칠했거나 손으로 칠한 줄 '수동' · 일부만 칠하고 채운 줄 '반자동' · 전부 만든 줄 '자동' · 비어 있으면 '빈칸'.
2-4. 용지의 게임마다 아래에 '다시'(그 게임만 새로) · '★ 담기'(여섯 개가 다 찼을 때만) 단추. 즐겨찾기 줄마다 '넣기'(고른 게임에 넣음) · '삭제'.
     '만든 번호' 줄(공 모양 목록)은 2026-11-07 재훈 님 지시로 없앴다.
     ★ '번호 이은 선 용지'는 예상번호 용지와 모양이 같아야 한다(2026-11-07 재훈 님): 바깥 틀 · 게임 5칸(A~E) · 칸 머리(이름표) · 7열 번호판 ·
       번호 타원의 크기 · 칸 아래 단추 줄까지 같은 크기로 맞추고, 다른 것은 색(흑백)과 내용뿐이다. 두 용지는 같은 크기 값을 함께 쓴다
       (데스크톱 번호 타원 20×24 · 간격 2 · 폰 42×44 · 간격 3). 선이 타원 중심에 맞도록 번호판 칸은 고정 크기다.
     번호 1~45 를 모두 보이고, 칠한 번호는 검은 타원 + 흰 숫자, 안 칠한 번호는 회색 테두리 타원. 선은 검정.
     처음에는 작은 수부터 차례로 자동으로 이어진다. 사용자가 고칠 수 있다: 번호 두 개를 차례로 누르면 선이 그려지고(첫 번호는 흰 바탕 + 검은 테두리로 바뀜),
     이미 이어진 두 번호를 누르거나 선을 누르면 지워진다. 게임마다 '지우기'(선 모두) · '자동'(작은 수부터 자동으로 되돌림) 단추. 이름표는 '선 자동' · '선 직접'.
     칠한 번호나 만든 번호가 바뀌면 그 게임의 선은 자동으로 돌아간다. 선 고치기는 스크립트가 있을 때만 된다(없으면 자동 선만 보인다 - 1-1).
     선 고친 내용을 즐겨찾기에 함께 저장할지는 미정(시안은 저장하지 않는다).
2-5. 폰(제안): 한 칸씩 세로로 쌓는다. 용지는 게임 탭(A~E) 하나씩 크게 보여 번호 칸을 44px 이상으로 둔다. '번호 이은 선 용지'도 같은 모양(게임 탭 A~E 하나씩 크게, 칸 크기 같음)이고 두 용지가 탭을 함께 쓴다. '1등 번호 히스토리' 단추도 같은 자리('5게임 만들기' 위)에서 목록이 펼쳐진다.
2-6. 시안의 색 · 크기 값은 확정되면 tokens.css 로 옮긴다(시안 값: 바탕 #F4F1EC · 글자 #1E2430 · 주 단추 #1F3A68 · 용지 붉은색 #C23B2E · 용지 바탕 #FFF4EE · 글꼴 Noto Sans KR).
